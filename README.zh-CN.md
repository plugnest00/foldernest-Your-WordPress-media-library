# PlugNest Media Folders

[English](README.md) | [繁體中文](README.zh-TW.md) | 简体中文

**给 WordPress 媒体库的真实文件夹——完全不碰你的文件。**

PlugNest Media Folders 为 WordPress 媒体库加入可嵌套、可拖拽的文件夹、标签、批量工具与使用状态扫描。它只写入分类数据：你的文件不会被移动、改名或改网址；停用插件后，网站与原来完全一样。

📦 **从 WordPress.org 安装**（审核通过后）· 🏠 [产品网站](https://media-folders.plugnest.dev/zh-cn.html) · 📖 [文档](https://media-folders.plugnest.dev/docs.html)

## 功能特色

- **文件夹就像文件夹**——可嵌套、拖媒体进去、钉选最爱、上色。可浏览整个媒体库，也可只看某个文件夹（含子文件夹）。
- **处处可用**——Gutenberg、传统编辑器、Elementor 与 WooCommerce 共用的媒体弹窗里都有同样的文件夹筛选；上传也能直接落进你正在浏览的文件夹。
- **标签、批量编辑、批量移动**——多选之后，一次完成改标题／替代文字、加标签、移动或删除。
- **使用状态扫描与清理**——扫描文章内容（含 Elementor JSON 与转义网址），「未使用」是真的未使用。删除前先检视；不经你点击不会删任何东西。
- **自动分类规则**——依文件名／类型规则自动归类，应用前可模拟预览。
- **完整操作记录可撤销**——每个批量动作都留存快照，一键还原。
- **三种语言**——内置英文、繁體中文、简体中文。
- **干净卸载**——可按需清除自建的分类法、项目与设置。

## 安装

1. 在 WordPress 后台前往**插件 → 安装插件**，搜索「PlugNest Media Folders」（或上传 zip）。
2. 启用——侧边菜单会出现「PlugNest Media Folders」。
3. 在左侧建立文件夹、把媒体拖进去，完成。

## 常见问题

**会改变我的文件路径或网址吗？** 不会。文件夹是分类层（分类法），不是物理目录。停用插件，一切照旧。

**停用插件后媒体会怎样？** 不会怎样。归类以分类关系存储，停用后只是休眠，重新启用即恢复。

**与 Elementor／Gutenberg／WooCommerce 兼容吗？** 兼容——文件夹筛选直接注入这些编辑器共用的标准媒体弹窗。
